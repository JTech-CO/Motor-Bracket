# 구조해석 상태

Rev G(196 × 162 × 180 mm)는 구조 FEA 미실시임. Rev E의 수치 및 Rev F의 형상 검사를 본 개정의 안전율이나 강도 승인으로 사용하지 않음.

상판 16 / 측판 18 / 하판 12 / 거싯 8 / 루트 R10은 유지함. 폭, 전면 창 위치, 측면 기둥 깊이, 레일과 잠금핀 위치를 변경했으므로 실제 접촉·적층 이방성·볼트 예압·크리프·열 조건을 넣어 새 형상으로 재해석해야 함.

해석용 시작 형상은 cad/step/SCMB-G10-L.step 및 R.step의 분리 솔리드 조립임. 모터 대리형상은 제작 대상이 아니며 모터 본체의 질량/출력축 하중 조건을 별도로 설정함. `src/geometry.py`의 bonded_analysis는 완전결합 비교체를 만드는 함수로 실제 접촉모형을 대체하지 않음.
